# Vizionix Renaissance

I’m giving you the complete HTML/CSS/JS of an existing VIZIONIX website.

Use this website as the foundation and rebuild it in React + TypeScript + Tailwind.

I want you to make the website BETTER, but do not redesign it into something completely different.

First analyze the existing website carefully and preserve:

- All existing content and French wording

- VIZIONIX branding

- Current color palette

- Typography style

- Overall layout and visual identity

- Navigation structure

- All pages and sections

- Expertise pages

- Team information

- Contact information

- Logo/assets

- Overall editorial/corporate aesthetic

Then improve the implementation and UX where appropriate:

- Make the layout more polished and consistent

- Improve responsive behavior on mobile/tablet

- Improve spacing and typography where needed

- Add subtle, professional animations

- Improve hover/focus states

- Improve navigation and mobile navigation

- Improve accessibility

- Make the contact form feel more professional

- Clean up the code into reusable React components

The result should feel like a polished, premium version of the SAME website — not a new website.

Do not add unnecessary features, backend, database, authentication, dashboard, or CMS.

For the contact form, keep it frontend-only for now. Use simple validation and a mailto/email solution, with the destination email stored in an easily editable constant.

Most importantly:

KEEP THE ORIGINAL VIZIONIX DESIGN LANGUAGE AND CONTENT.

Improve what is there 
rather than replacing it.

Do not use generic SaaS design, gradients, glassmorphism, excessive rounded cards, stock imagery, or unnecessary visual effects.

Use the provided HTML as your primary source of truth.
